# رابط همتایار

رابط فارسی با سبک تیره همسان با `CGC/HamtayarDemo`: پنل سرمه‌ای، رنگ آبی، نوار کناری و کارت‌های فضای کاری.

## اجرای رابط اصلی

در PowerShell، از مسیر مخزن:

```powershell
cd D:\Hamtayar-GitHub\hamtayar-ui
npm ci
npm run dev
```

آدرس: **http://127.0.0.1:5174**. پورت ثابت است تا با برنامه کد تداخل نداشته باشد؛ اگر اشغال باشد Vite خطا می‌دهد.
Node 22 یا بالاتر لازم است. ورود: نام کاربری `demo` و گذرواژه `Hamtayar123!`.

## اجرای همتایار کد

منوی «همتایار کد» و کارت مربوط به آن، همان رابط واقعی **HamtayarDemo** را در همان تب باز می‌کنند.
این لینک برنامه را خودکار اجرا نمی‌کند؛ ابتدا در پنجره PowerShell جداگانه:

```powershell
cd D:\Hamtayar-GitHub\CGC\HamtayarDemo
.\scripts\start-dev.ps1
```

این دستور برای محیط از قبل آماده‌شده است. در نصب نخست طبق `CGC/HamtayarDemo/README.md`،
اسکریپت setup، تنظیمات `.env`، CGC و Neo4jها را آماده کنید. این رابط روی **http://127.0.0.1:5173**
و API آن روی پورت ۸۰۰۰ اجرا می‌شود. مسیر واقعی مخزن خودتان را جایگزین کنید.

| برنامه                    | آدرس پیش‌فرض            |
| ------------------------- | ----------------------- |
| همتایار اصلی              | `http://127.0.0.1:5174` |
| همتایار کد (HamtayarDemo) | `http://127.0.0.1:5173` |

برای آدرس محلی دیگر، `.env.example` را به `.env.local` کپی کنید و `VITE_CGC_UI_URL` را تغییر دهید؛ سپس Vite را دوباره اجرا کنید.
لینک فقط HTTP(S) روی loopback را می‌پذیرد. لینک به رابط کد، ادعای آماده بودن backend یا ایندکس آن نیست.

## فرم‌های فعلی

- اسناد و فیلتر پرسش‌وپاسخ فقط دو فراداده دارند: **مرکز** و **نوع سند**.
- مرکز متن آزاد است تا نام مراکز واقعی سازمان حدس زده نشود.
- **سطح دسترسی فرد** در فرم پرسش، یک مقدار توصیفی و نمایشی است؛ مجوز واقعی ایجاد نمی‌کند و به جای هویت معتبر Padeen ارسال نمی‌شود.
- صفحه و منوی تنظیم فراداده فعلاً در دسترس نیستند؛ مسیر قدیمی به نمای کلی برمی‌گردد.
- تنظیمات قدیمی مرورگر نمی‌توانند فیلدهای حذف‌شده را به فرم‌ها یا درخواست فعلی برگردانند. داده مرورگر پاک نشده است.

ورود اسناد و پرسش‌وپاسخ در Demo از نمونه محلی استفاده می‌کنند؛ هیچ فایل یا پرسشی به سرویس ارسال نمی‌شود.
API آنها هنوز تا تأیید سرویس واقعی مسدود است. همتایار کد برنامه جداگانه خودش را باز می‌کند و Demo/API این رابط بر آن اعمال نمی‌شود.

## ساخت و بررسی

```powershell
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

آدرس پیش‌نمایش ساخت: `http://localhost:4173`. بررسی این نسخه با Node `24.22.1` و npm `11.9.0` در Linux انجام شد.
نتایج در `docs/verification.md` و مرز اتصال در `docs/integration-map.md` آمده است.
برای توقف سرور `Ctrl+C` را بزنید.
