# دموی رابط همتایار

رابط فارسی و RTL برای ورود اسناد، پرسش‌وپاسخ و پایگاه کد، با تنظیمات متادیتای قابل ویرایش.
حالت پیش‌فرض **Demo** است و بدون Python، Docker، Qdrant، Neo4j یا کلید مدل اجرا می‌شود.
نتیجه‌ها نمونه ثابت هستند؛ فایل‌ها واقعاً پردازش نمی‌شوند.

## اجرای سریع در PowerShell

Node.js نسخه ۲۲ یا جدیدتر و npm لازم است. محیط بررسی این تحویل: Node `24.22.1`، npm `11.9.0`، Linux.
از پوشه مخزن به پوشه UI بروید:

```powershell
cd D:\Hamtayar-GitHub\hamtayar-ui
npm ci
npm run dev
```

اگر مخزن را در مسیر دیگری دارید، مسیر دستور `cd` را عوض کنید.
آدرس چاپ‌شده توسط Vite را باز کنید؛ پیش‌فرض: **http://localhost:5173**.

| ورود نمایشی | مقدار          |
| ----------- | -------------- |
| نام کاربری  | `demo`         |
| گذرواژه     | `Hamtayar123!` |

این حساب عمومی فقط برای نمایش رابط است و احراز هویت سرویس نیست.
برای توقف سرور در PowerShell کلیدهای `Ctrl+C` را بزنید.

## دیدن سه دمو

1. وارد شوید و «ورود اسناد» را باز کنید. یک یا چند PDF، DOCX، TXT یا Markdown انتخاب کنید؛
   مثلاً در «فضای دانشی مشترک» مقدار `team-docs` بنویسید. متادیتای هر فایل را مستقل تغییر دهید،
   پیش‌نمایش را ببینید و «اجرای نمایش» را بزنید. نتیجه هر فایل جداست.
2. در «پرسش‌وپاسخ» سؤال بنویسید، اطلاعات توصیفی و فیلترهای دلخواه را انتخاب کنید و
   «نمایش پاسخ نمونه» را بزنید. پاسخ و منابع ثابت‌اند و از فایل شما استخراج نشده‌اند.
3. در «پایگاه کد» یک ZIP یا RAR انتخاب کنید، نام پروژه را بنویسید و «اجرای نمایش کد» را بزنید.
   مراحل و گزارش‌ها نمونه هستند؛ آرشیو استخراج نمی‌شود.
4. در «تنظیم فراداده» فیلد سند یا کاربر اضافه کنید. گزینه «قابل فیلتر» فقط برای سند است.
   مقدار boolean سه حالت تعیین‌نشده، بله و خیر دارد؛ صفر و خیر مقدار معتبرند.
5. هنگام اجرای عملیات، تغییر حالت قفل است. رفتن به صفحه دیگر نتیجه را نگه می‌دارد؛
   تغییر حالت یا خروج، اطلاعات موقت را پاک می‌کند.

## ساخت نسخه قابل نمایش

```powershell
npm run build
npm run preview
```

آدرس پیش‌فرض پیش‌نمایش **http://localhost:4173** است. فایل `dist/index.html` را مستقیم
با دوبار کلیک باز نکنید؛ از سرور preview استفاده کنید. برای میزبانی دیگر، مسیرهای SPA
باید به `index.html` برگردند. انتشار عمومی جزو این تحویل نیست.

## تنظیمات و مرز API

برای Demo فایل env لازم نیست. برای آماده‌سازی تنظیمات محلی:

```powershell
Copy-Item .env.example .env.local
```

آدرس‌ها و timeoutها غیرمحرمانه‌اند. هیچ token، رمز واقعی یا کلید provider در `VITE_*` نگذارید.
تغییر env به راه‌اندازی دوباره Vite نیاز دارد.

**API در این تحویل مسدود است**؛ وارد کردن آدرس به‌تنهایی آن را فعال نمی‌کند. client همتایار
با mock آزموده شده، اما نسخه اجراشده، CORS، سقف آپلود و اجراکننده تأیید زنده نشده‌اند.
Q&A در کد فعلی احراز هویت آماده ندارد و 401 می‌دهد. CGC به تأیید قرارداد و ابزار و دو Neo4j
نیاز دارد. جزئیات و گام بعدی در [نقشه اتصال](docs/integration-map.md) آمده است.

## نگهداری اطلاعات

تعریف فیلدها فقط در همین مرورگر با کلید `hamtayar-demo-ui.metadata.v1` ذخیره می‌شوند.
بازگردانی پیش‌فرض‌ها به سایر کلیدها دست نمی‌زند. خطای ذخیره‌سازی با هشدار و حالت موقت همراه است.
فایل، پاسخ، تاریخچه و اطلاعات توصیفی در حافظه‌اند و با refresh یا خروج پاک می‌شوند؛
نشست ورود در همان تب با refresh می‌ماند. هیچ رمز عبوری در storage ذخیره نمی‌شود.

## کنترل کیفیت

```powershell
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

نتیجه نهایی اجرای این دستورها در [گزارش بررسی](docs/verification.md) ثبت شده است.
تست‌های adapter با mock هستند؛ اجرای موفق آنها اتصال زنده را ثابت نمی‌کند.

## چک دستی باقی‌مانده

- با صفحه‌کلید از ورود تا هر سه عملیات بروید؛ focus و labelها را بررسی کنید.
- در عرض‌های ۱۳۶۶×۷۶۸ و ۳۹۰ پیکسل، نام فایل طولانی، JSON، navigation و دکمه‌ها را بررسی کنید.
- در DevTools/Network مطمئن شوید Demo هیچ درخواست عملیاتی به سرویس ندارد.
- persistence را با بسته‌شدن و بازشدن مرورگر بررسی کنید؛ پذیرش کاربران واقعی هنوز انجام نشده است.
